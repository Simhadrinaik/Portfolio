# Personal Portfolio Website – Simhadri Naik Mudavath

A clean, modern, and highly performant personal portfolio website built with **React, Vite, Tailwind CSS, and Framer Motion**.

This portfolio showcases my technical skills, academic background, software development projects, achievements, and professional experience through a responsive and animation-rich user interface.

## 🚀 Features

- Modern and responsive user interface
- About Me section
- Technical Skills
- Academic Background
- Projects Portfolio
- Competitive Programming
- Professional Contact Section
- Resume Access
- Smooth animations using Framer Motion
- Dark mode support

## 🛠️ Tech Stack

- JavaScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
